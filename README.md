# Admin Dashboard Template

Responsive static admin dashboard using HTML, Tailwind CDN, and vanilla JavaScript.

## Views
- Client Management: sortable/filterable table.
- Service Scheduler: day/week/month views.
- Invoice Generator: data-entry form with PDF export.

## Deploy
1. Push to `main`.
2. Set GitHub Pages source to **GitHub Actions**.
3. The workflow publishes the site automatically.
